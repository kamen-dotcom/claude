# Interactive Questionnaire

A beautiful, responsive questionnaire web application built with HTML, CSS, and JavaScript.

## Features

- 📝 6 different question types (text input, radio buttons, checkboxes, textarea)
- 🎨 Modern, gradient UI design
- ✅ Form validation
- 📱 Fully responsive (mobile-friendly)
- ⚡ Smooth animations and transitions
- 🔄 Interactive results display

## How to Enable GitHub Pages

To access this questionnaire via a public URL, follow these steps:

1. Go to your GitHub repository settings
2. Navigate to **Pages** in the left sidebar
3. Under **Source**, select the branch: `claude/review-changes-mkciabk5v33pczvj-uj7Fk`
4. Select the folder: `/ (root)`
5. Click **Save**

After a few minutes, your questionnaire will be available at:
`https://[your-username].github.io/claude/`

## Local Usage

You can also open the `index.html` file directly in your web browser to use the questionnaire locally.

## Questions Included

1. Name (text input)
2. Favorite programming language (multiple choice)
3. Years of programming experience (multiple choice)
4. Technologies of interest (checkboxes)
5. Learning goals (text area)
6. How you heard about this (multiple choice)

## Customization

Feel free to customize the questions by editing the `index.html` file. The structure is straightforward and well-commented.
